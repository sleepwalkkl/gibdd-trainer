# gibdd-trainer
Личный тренажёр теоретического экзамена ГИБДД: билет ПДД, практика и работа над ошибками.

После изменения опубликованных файлов выполните `node scripts/cache-version.mjs --write` и `node scripts/check.mjs`. Версия офлайн-копии зависит от содержимого файлов. Новая копия активируется после закрытия вкладок старой версии.
